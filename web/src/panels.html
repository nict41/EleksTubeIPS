Panels

With panels, each tube shows a full-screen picture sent to the clock from Home Assistant, instead of a clock face. Each picture is 135x240 pixels, sent over HTTP as raw pixels, QOI or JPEG, one tube at a time or a whole screen at once, and the clock can play a transition as it changes.

Turn them on with Display set to Panels on the Clock page, so all six tubes show pictures, or with Number of Digits set to Four + Panel, so only the last tube does and the other four show the time as usual.

    Test pattern

    Draws a test pattern on every panel tube, made by the clock itself, to check the tubes and try the transitions. It stays for three seconds, then the tubes ask Home Assistant for their pictures again.

    Use with Home Assistant

    The Tube Display Home Assistant app renders screens from your Home Assistant states, with rotation and a visual editor, and pushes them to the tubes. The clock's button steps to its next screen while panels are showing.

    To send a picture to a tube by hand, the body is the raw pixels, RGB565 big-endian, row by row, exactly 135*240*2 = 64800 bytes for a whole tube (or add &format=qoi or &format=jpeg for a compressed picture):

    curl -H 'Content-Type: application/octet-stream' --data-binary @tube.rgb565 "http://<clock>/panel?tube=0"

    A whole screen in one request, with a transition, goes to POST /panel/batch, see the user guide.

    GET /panel replies which tubes are panel tubes and which still need a picture, as the status above shows.
